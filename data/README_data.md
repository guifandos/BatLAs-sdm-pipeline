# Data Directory — Structure and Sources

This document describes the expected data structure, column formats, and
sources for the Iberian Bat SDM pipeline.

**Real survey data are not distributed with this repository** for
conservation and privacy reasons. To run the pipeline without real data,
use the simulated data generator: `source("examples/simulate_data.R")`.

---

## Directory layout

```
data/
├── metadata/              # Ecological metadata (versioned in Git)
│   ├── especies_gremios.csv
│   ├── gremios_refugio.csv
│   ├── gremios_alimentacion.csv
│   ├── complejos_taxonomicos.csv
│   └── diccionario_variables.csv
├── raw/                   # Raw input data (NOT in Git)
│   ├── presencias/        # Occurrence records
│   ├── variables/         # Environmental variable files
│   └── shapefiles/        # UTM 10×10 km grid shapefiles
├── processed/             # Intermediate outputs from Phase 0 (NOT in Git)
├── modelado_ready/        # Model-ready PAxENV matrices (NOT in Git)
└── simulated/             # Simulated data for examples (versioned)
```

## Raw data sources

### Occurrence records (`data/raw/presencias/`)

Excel file with bat occurrence records from multiple survey methods.

| Column | Type | Description |
|---|---|---|
| `especie` | character | Species scientific name |
| `cuadricula_utm_10x10` | character | UTM 10×10 km cell ID (e.g., "30TUN65") |
| `metodo` | character | Survey method: "acustica", "captura", "cuevas", "otros" |
| `presencia` | integer | 1 = detected, 0 = surveyed but not detected |
| `anio` | integer | Year of observation (optional, for temporal filtering) |

**Source:** Bat Monitoring Programme (MITECO / SECEMU / Tragsatec),
aggregating data from acoustic surveys, mist-netting campaigns, roost
censuses, and opportunistic records across the Iberian Peninsula and
Balearic Islands.

### Environmental variables (`data/raw/variables/`)

Two Excel files (Peninsula and Balearic Islands) with ~90 candidate
environmental variables per UTM cell. Variables are grouped into:

| Category | Examples | Source |
|---|---|---|
| Climatic | Bio01 (mean annual temp.), Bio05, Bio06, Bio12 | WorldClim v2 / AEMET |
| Topographic | Altitude (mean), Slope (mean) | SRTM 90m |
| Geological | Karst coverage, lithology proportions | IGME geological maps |
| Land cover | CORINE categories (forest, urban, water, etc.) | CORINE Land Cover 2018 |
| Vegetation | Forest type abundance, Shannon diversity | National Forest Inventory |

Additionally, two CSV files provide geological data:
- `10x10_Karst_PIBAL.csv` — Karst surface proportions per cell
- `10x10_lito_COLOR_PIBAL.csv` — Lithological composition per cell

### UTM grid shapefiles (`data/raw/shapefiles/`)

- `Malla10x10_clip.shp` — UTM 10×10 km grid for the Iberian Peninsula
  (ETRS89 / UTM zone 30N, EPSG:25830)
- `Malla10x10_BAL_Clip_nueva.shp` — UTM 10×10 km grid for the Balearic
  Islands (UTM zone 31, reprojected to zone 30 during loading)

## Processed data (generated by Phase 0)

### `data/processed/PAxENV_all_metodos.rds`

Main model-ready data frame. One row per UTM cell.

| Column pattern | Description |
|---|---|
| `CUADRICULA` | UTM cell ID |
| `X_UTM`, `Y_UTM` | Cell centroid coordinates (ETRS89 UTM 30N) |
| `sp_<species name>` | Presence/absence for each species (1/0/NA) |
| `<variable name>` | Environmental predictor value |
| `m_acustica`, `m_captura`, `m_cuevas`, `m_otros` | Survey method indicators (0/1) |
| `n_metodos` | Number of survey methods covering this cell |
| `muestreado` | 1 if cell was surveyed by at least one method |

### `data/processed/predictores_SEO_GEO.rds`

List object with the full predictor grid:
- `$vars_all` — Data frame with all environmental variables
- `$CUADRICULA` — Cell IDs
- `$X_UTM`, `$Y_UTM` — Coordinates

### `data/processed/esfuerzo_por_metodo.rds`

Sampling effort summary per cell (method indicators and total count).

## Metadata files (versioned)

### `especies_gremios.csv`

Species ecological classification. Columns:
- `especie` — Scientific name
- `refugio` — Shelter guild: Cavernicola, Arboricola, Fisuricola, Generalista
- `alimentacion` — Foraging guild: Forestal, Ripario, Generalista, Mosaico,
  Pastizal, Aereo
- `modelar` — TRUE/FALSE: whether the species has enough data for modelling
- `complejo` — Cryptic species complex name (if applicable)
- `notas` — Free-text notes

### `gremios_refugio.csv` / `gremios_alimentacion.csv`

Maps each guild category to its priority environmental variables.
- `categoria` — Guild category name
- `variables_prioritarias` — Comma-separated list of priority variables
- `descripcion` — Guild description

### `complejos_taxonomicos.csv`

Defines cryptic species complexes (species that cannot be reliably
distinguished by certain survey methods and are modelled jointly).

### `diccionario_variables.csv`

Variable dictionary with columns: `variable`, `tipo` (Climatica, Topografica,
Geologica, Cobertura), `unidad`, `fuente`, `descripcion`.

## Simulated data (`data/simulated/`)

Generated by `examples/simulate_data.R` with `set.seed(42)`:

| File | Description |
|---|---|
| `PAxENV_simulated.rds` | ~5400 cells, 3 species, ~40 variables |
| `grid_simulated.rds` | Predictor grid (same structure as processed) |
| `esfuerzo_simulated.rds` | Simulated sampling effort |
| `especies_gremios_sim.csv` | Guild assignments for 3 synthetic species |

The simulated species are:
1. **Cavebat simulated** — cavernicolous/forest, ~25% prevalence
2. **Treebat simulated** — arboreal/forest, ~15% prevalence
3. **Generalbat simulated** — generalist/generalist, ~45% prevalence

These allow the full pipeline to run end-to-end without real data.
